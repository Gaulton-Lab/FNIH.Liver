# 03 Cell type composition

### `260302_WE_scCODA.ipynb`
scCODA compositional analysis of all cell types, all sub-types, and hepatocyte sub-types. Covers ordinal fibrosis stage, each MASLD state vs. control, and low/high fibrosis pairwise comparisons. B cells are the reference cell type and FDR is 10%.

### `260302_WE_scCODA_R_Plotting.ipynb`
Summary tables and plots of the scCODA results (Figures 1G and 6D).

### `260203_miloR.ipynb`
miloR differential abundance of hepatocyte neighborhoods (max 250 cells/donor) across fibrosis stage and each MASLD state vs. control (Supplementary).
