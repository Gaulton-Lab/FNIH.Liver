# 09 Hepatocyte trajectory

### `241113_WE_Liver_Hepatocyte_Union_Peaks.ipynb`
Builds a hepatocyte-specific consensus peak matrix and merges it with hepatocyte Droplet Paired-Tag data. Runs Monocle3 pseudotime from the inflammatory hepatocyte cluster in Fib+ donors, then plots the pseudotime distributions by sub-type and heatmaps of the top 50 genes up-regulated in Fib+ MASH along pseudotime (Figure 6J).
